# Mapping PM2.5 Exposure and the Demographic Index of People of Color and Low-Income Communities in Yakima County

## Purpose
This repository contains two maps of Yakima County in Washington State that help identify potential environmental justice concerns. Environmental justice seeks to ensure that all communities are protected from disproportionate environmental burdens that historically have been overlooked contributing to unequal exposure to pollution and environmental hazards. This repository examines whether higher concentrations of PM2.5 are associated with areas in Yakima County that have larger populations of low-income residents and communities of color.

## Overview
Highlights:
- ej.qmd file: Code for the two maps of Yakima County. The first map displays the EJScreen Demographic Index, highlighting low-income communities and communities of color. The second map shows PM2.5 concentrations, which measure fine particulate matter 2.5 micrometers or smaller in diameter, across the county. 
- Data folder: houses EJ Screen data, EJ Screen data index, and the technical document of the EJ Screen data.

## Data Access
The EJ Screen data originally is from the United States Environmental Protection Agency’s EJScreen: Environmental Justice Screening and Mapping Tool. However, this EJ Screen tool and data have been removed from the EPA website and an unofficial version is now stored on this webpage: https://pedp-ejscreen.azurewebsites.net/.
The EJ Screen dataset used in this analysis was obtained from a downloadable data folder provided through the Environmental Data Science 223 course at the University of California of Santa Barbara website by Annie Adams: https://eds-223-geospatial.github.io/assignments/HW1.html.
